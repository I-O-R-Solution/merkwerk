"Gestaged", "committet" und "gepusht" sind drei verschiedene Zustaende. Im Chat immer den tatsaechlichen nennen.

**Why:** Ein "ist gesichert" fuer eine Datei, die nur im Index lag, kostet beim naechsten Rechnerwechsel die Arbeit.

**How to apply:** Bei jeder Erfolgsmeldung zu Git den Zustand woertlich nennen, bei "gepusht" den Remote dazu.
